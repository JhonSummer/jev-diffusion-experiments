# The first steering experiment

Imagine a drawing machine making a creature that looks like a cathedral. We ask a helper, Jev, to make it look more alive without ruining the building shape or its surroundings.

The machine tries a few short routes from the same starting point. Other tools describe patches of the picture and give rough similarity scores. Jev uses those measurements to choose a route. We also try routes chosen without Jev.

This is a small, three-seed practice run. The patch finder is a separate helper, not a new part inside the drawing machine. A better similarity score does not automatically mean a better picture.
