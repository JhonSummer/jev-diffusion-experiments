# Which little moves shaped the final picture?

Imagine watching a drawing appear one pencil stroke at a time. To understand a stroke, we also make a version where that stroke is left out.

This notebook follows every denoising step for four methods and an ordinary route. It starts from the same hand with eight different noise patterns. Some patterns help develop our guesses; the remaining ones check whether those guesses repeat.

Some effects repeat: for example, FreeU often makes much of its difference early. Other effects change with the starting noise. The arrow from an ordinary picture to an edited picture tells us how it changed, not whether it improved. We cannot give that final arrow to a live controller before the picture exists.
