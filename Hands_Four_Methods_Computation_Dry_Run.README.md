# Try four knobs and watch what moves

Instead of treating four research ideas as magic boxes, we open the drawing machine and try their knobs on the same hand.

PAG and SoftPAG change how information is mixed. Self-Guidance nudges a measured internal pattern toward a target. FreeU changes the balance between two paths through the machine.

We take short previews and continue some drawings, measuring how each knob changes the machine's next move. Different knobs really do produce different changes. Some internal targets move as requested, but that does not prove the fingers got better. Jev helps choose further measurements here; it is not the controller making the final pictures.
