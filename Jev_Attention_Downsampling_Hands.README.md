# Can a coach steer the hand-drawing machine?

Imagine the drawing machine has many little helpers passing notes to each other. Attention is part of that note-passing system. This notebook first changes how many notes get passed, then lets Jev change which notes matter.

We keep returning to the original seed-123 hand. The notebook grows from simple comparisons into repeated choices, previews, attention edits, and local refinement. Later sections give Jev more knobs and more descriptions of what happened.

This is the long experiment diary, including ideas that did not work. Changing the hand's pixels is not the same as fixing its fingers. The experiments did not establish a dependable way for Jev to improve hand anatomy, and the picture-review helper was not reliable enough to settle that question.
