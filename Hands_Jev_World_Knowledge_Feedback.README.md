# Give the coach a memory and a picture reviewer

Jev knows things about the world, but it needs a useful description of what the drawing machine is actually doing. Here we give it measurements, earlier trial information, and descriptions from a picture-review model.

At each stop, it can keep going normally or try a set of changes together. We try eight noise patterns and record every choice, including rejected ideas.

Across 80 decisions, Jev chose the ordinary route every time. The suggested changes did move pixels, but the feedback did not establish that they made a better hand. We also found missing information in its memory and a problem with how one question's answer reached the next question. The final pictures therefore do not show a Jev-controlled improvement.
