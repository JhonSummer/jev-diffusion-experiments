# Does Jev follow the facts or the labels?

Imagine showing someone the same puzzle twice, but swapping the names of the pieces. A good answer should still point to the same useful piece.

This notebook checks Jev's choices around saved moments in the drawing process. It changes the evidence available and how choices are described, and includes paired trials and review without revealing which method made which picture.

The point is to test the chooser before trusting its explanations. A convincing sentence is not proof of a good choice. These checks are about decision reliability; they are not proof that Jev can make better hands.
